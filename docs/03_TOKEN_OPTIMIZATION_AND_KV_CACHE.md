# Contexto útil para agentes

Cargar [AGENTS.md](../AGENTS.md), el contrato del área y los archivos necesarios
para decidir el cambio. Mantener una fuente por regla y enlazarla desde skills,
reglas y guías. No repetir manuales completos en cada tarea o mensaje delegado.

Los prompts de subtareas deben indicar objetivo, propietario de archivos,
contratos compartidos y aceptación. Usar un formato legible y el detalle que
necesita el trabajo; no imponer JSON ni límites de líneas arbitrarios.

Las cachés de prefijos pueden reducir coste y latencia según proveedor, modelo
y condiciones de la sesión. Este repositorio no garantiza porcentajes de ahorro.
No conservar instrucciones obsoletas ni omitir contexto necesario para favorecer
una caché hipotética. Medir consumo y tiempos cuando haya un problema real.
