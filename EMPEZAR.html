Instalar dbCMS desde el navegador

Este paquete ya incluye las dependencias PHP y los recursos web compilados. No necesitas Composer, Node, Artisan ni acceso SSH.

1. Sube y extrae el ZIP

Desde el administrador de archivos de Plesk o cPanel, sube el archivo dbcms-installer-v1.0.2.zip al directorio del dominio y extráelo.

2. Configura el directorio público

Si tu panel permite elegir la raíz del dominio, apunta a la carpeta public. El paquete también incorpora una regla compatible para alojamientos Apache cuya raíz de dominio no se pueda cambiar.

3. Abre el dominio

Visita tu dominio con HTTPS. dbCMS preparará de forma segura su configuración inicial y mostrará el asistente.

4. Indica la base de datos

Usa una base MySQL o MariaDB vacía. Si el hosting no permite que dbCMS la cree, créala desde Plesk/cPanel y copia en el asistente el servidor, puerto, nombre, usuario y contraseña.

5. Termina la instalación

Revisa la URL, crea el administrador y elige la marca y el tema. El instalador preparará las tablas, el almacenamiento y el acceso del CMS.

Si aparece un aviso de permisos: marca como escribibles para el usuario PHP las carpetas storage y bootstrap/cache, y permite crear el archivo .env en esta carpeta. No uses permisos 777.

Después de instalar, elimina este archivo si no quieres conservar la guía en el servidor. Las actualizaciones y opciones avanzadas están documentadas en docs/DEPLOYMENT_GUIDE.md.
